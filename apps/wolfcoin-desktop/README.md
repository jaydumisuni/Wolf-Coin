# Wolf-Coin Desktop v0.6 (development)

Electron 37.2.6 Chromium host with isolated persistent browser profiles, bundled nine-screen HTML and D-XQT WebAssembly. Primary UI has context isolation, no Node integration and narrow wolfNative bridge.

Development: npm install; npm start. Test using the local fixture from test_fixture.cjs and isolated profiles. The independent backend decides strategies and action requests. Browser observations are candidate-only.
